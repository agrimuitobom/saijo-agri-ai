# 西農スマートアグリLab

愛媛県立西条農業高等学校のスマート農業実践と、Raspberry Pi を使ったセンサーづくりの教材を、
地域そして日本中に発信するプラットフォームのフロントエンド(モックアップ)です。
スマートフォンでの利用を想定した、モバイルファースト・高コントラストな UI を採用しています。

## 画面構成

| 画面 | パス | 内容 |
| --- | --- | --- |
| ホーム | `/` | 学校紹介ヒーロー、ハウスのセンサーライブ値、人気教材、PLANTDOC紹介、最新活動 |
| つくる | `/learn` | ラズパイセンサー教材の一覧(難易度・時間・費用つき) |
| 教材詳細 | `/learn/[id]` | 部品リスト、手順、サンプルコード、安全上の注意 |
| 活動記録 | `/reports` | 生徒・先生・部活動・校外からの報告をカテゴリで絞り込めるタイムライン |
| 投稿する | `/post` | カテゴリ選択、大きな入力フォーム、カメラ起動対応の写真アップロード |

## 技術スタック

- Next.js 15 (App Router) / React 19 / TypeScript
- Tailwind CSS v4(`app/globals.css` の `@theme` でデザイントークンを定義)
- lucide-react(アイコン)

## UI 設計ルール

- **モバイルファースト**: 1カラムレイアウト+下部固定ナビゲーション。タップ領域はすべて 44px 以上
- **高コントラスト**: 屋外の太陽光下でも読みやすい濃色テキストと太字を基本にする
- **配色**: 葉の緑(`leaf-*`)と土のアースカラー(`soil-*`)を基調に、余白を活かしたカード UI
- **アクセシビリティ**: `aria-*` 属性、`focus-visible` リング、16px 以上のフォント(iOS ズーム防止)。センサーの状態表示は色だけに頼らずアイコン+ラベルを併記

## 開発コマンド

```bash
npm install       # 依存関係のインストール
npm run dev       # 開発サーバー (http://localhost:3000)
npm run build     # 本番ビルド
npm run start     # 本番サーバー
```

現在はフロントエンドのモックアップ段階のため、センサー値・教材・活動記録はすべて `lib/data.ts` のダミーデータです。

## 既存の AI 診断アプリ(`app.py`)

リポジトリには Streamlit + Gemini による病害虫診断アプリ「西農PLANTDOC」も含まれています。
ホーム画面で紹介しており、将来的に本プラットフォームからリンク・統合する想定です。

```bash
pip install -r requirements.txt
streamlit run app.py
```
