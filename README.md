# アグリシェア — 農業情報共有プラットフォーム

農家向けの情報共有プラットフォームのフロントエンド(モックアップ)です。
スマートフォンでの屋外利用を想定した、モバイルファースト・高コントラストな UI を採用しています。

## 画面構成

| 画面 | パス | 内容 |
| --- | --- | --- |
| ダッシュボード | `/` | 今日の天気・作業メモ、病害虫アラート、市況サマリー、最新投稿 |
| みんなの広場 | `/timeline` | ノウハウ・病害虫・質問・市況をカテゴリで絞り込めるタイムライン |
| 投稿作成 | `/post` | カテゴリ選択、大きな入力フォーム、カメラ起動対応の写真アップロード |

## 技術スタック

- Next.js 15 (App Router) / React 19 / TypeScript
- Tailwind CSS v4(`app/globals.css` の `@theme` でデザイントークンを定義)
- lucide-react(アイコン)

## UI 設計ルール

- **モバイルファースト**: 1カラムレイアウト+下部固定ナビゲーション。タップ領域はすべて 44px 以上
- **高コントラスト**: 屋外の太陽光下でも読みやすい濃色テキストと太字を基本にする
- **配色**: 葉の緑(`leaf-*`)と土のアースカラー(`soil-*`)を基調に、余白を活かしたカード UI
- **アクセシビリティ**: `aria-*` 属性、`focus-visible` リング、16px 以上のフォント(iOS ズーム防止)

## 開発コマンド

```bash
npm install       # 依存関係のインストール
npm run dev       # 開発サーバー (http://localhost:3000)
npm run build     # 本番ビルド
npm run start     # 本番サーバー
```

現在はフロントエンドのモックアップ段階のため、天気・市況・投稿はすべて `lib/data.ts` のダミーデータです。

## 既存の AI 診断アプリ(`app.py`)

リポジトリには Streamlit + Gemini による病害虫診断アプリ「西農PLANTDOC」も含まれています。

```bash
pip install -r requirements.txt
streamlit run app.py
```
